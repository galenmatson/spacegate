# Astronomical Evidence and Provenance

Astronomy combines measurements made by different instruments, at different epochs, with different models and uncertainty. Two reputable catalogs can disagree without either being careless: they may observe different components, fit different models, or publish improved releases.

Spacegate separates four roles:

- **CORE** holds reviewed canonical identity and containment.
- **ARM** holds source evidence, selected facts, and reproducible derivations.
- **DISC** holds presentation policies, screens, rankings, and narration.
- **RIM** holds fictional and user-authored worldbuilding overlays.

A source value is not the same thing as a derivation, and a derivation is not the same thing as a presentation assumption. Smart Tags retain those distinctions through their layer, evaluator version, source policy, and selected-fact references.

## Reproducibility

Tag assignments are compiled from an immutable Public Read build and a reviewed, versioned registry. Rebuilding the same inputs produces the same logical assignment hashes. Context-dependent ideas such as “visible now” require an observer and time, so they are evaluated live and are not stored as intrinsic facts about the star.
